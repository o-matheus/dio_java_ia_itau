## Resumo da aula

## Revisão: inteligência artificial

No entendimento relatado, IA está ligada à tentativa humana de simular a inteligência humana e permitir comunicação em linguagem natural com máquinas.

**Ajuste conceitual:** inteligência artificial é um campo mais amplo, voltado a construir sistemas capazes de realizar tarefas associadas à inteligência, como reconhecer padrões, planejar, aprender e processar linguagem. Conversar em linguagem natural é uma aplicação de IA; nem todo sistema de IA conversa ou busca reproduzir exatamente o funcionamento humano.

## Revisão: Machine Learning

Matheus compreendeu Machine Learning como o uso de modelos matemáticos para aprimorar o conhecimento da máquina, tanto no aprendizado quanto na produção de respostas.

**Ajuste conceitual:** Machine Learning utiliza dados para ajustar modelos e aprender padrões. Durante o **treinamento**, o processo ajusta parâmetros; durante a **inferência**, o modelo utiliza o que foi aprendido para produzir um resultado a partir de uma entrada. Produzir uma resposta normalmente não significa treinar o modelo novamente ou atualizar uma base de conhecimento.

## O que é Deep Learning

**Deep Learning (aprendizado profundo)** é uma área de Machine Learning que utiliza **redes neurais com múltiplas camadas**. Essas camadas aprendem representações dos dados que ajudam a realizar tarefas como reconhecer imagens, processar linguagem e gerar conteúdo.

O relato destaca a capacidade de usar contexto e relacionar padrões para produzir respostas mais completas. Isso é uma aplicação possível dessas redes, mas não é a definição de Deep Learning: o conceito central é o aprendizado por redes neurais profundas. Modelos de Deep Learning também podem realizar tarefas simples, como classificar uma imagem.

**Relação entre os conceitos:** Deep Learning faz parte de Machine Learning, que faz parte do campo de inteligência artificial.

## Exemplo da aula: revista com Pokémon na capa

O professor mostra uma revista **Jogo Veio** com Pokémon na capa.

Segundo o relato, a imagem pode levar quem assiste a lembrar de outros elementos:

- O desenho animado de Pokémon.
- A TV Globinho.
- Os jogos de Pokémon.
- Experiências pessoais e sentimentos de gostar ou não gostar da franquia.

O exemplo ilustra como um mesmo estímulo pode despertar associações diferentes em pessoas diferentes, conforme suas experiências.

Na conexão com IA, um modelo pode relacionar elementos da entrada a padrões aprendidos no treinamento e usar essas relações para produzir um resultado contextualizado. Essa comparação é uma analogia: não demonstra que o modelo tenha lembranças pessoais ou sentimentos como os de um ser humano.

## Inferência, contexto e associações

No relato, “inferência” aparece no sentido de estabelecer conexões e tirar conclusões a partir de um contexto.

Em Machine Learning, **inferência** também tem um significado técnico mais amplo: executar um modelo treinado para obter um resultado. Reconhecer um objeto, classificar uma mensagem ou gerar texto são exemplos de inferência, mesmo quando não envolvem uma conclusão elaborada.

As associações aprendidas podem ajudar a produzir respostas relevantes, mas também podem levar a conexões incorretas. Uma resposta mais detalhada não é necessariamente mais correta.

## Neurônios artificiais e camadas

O professor menciona neurônios artificiais como parte das conexões realizadas pelas redes.

Como complemento, um **neurônio artificial** é uma unidade matemática que combina entradas usando pesos, normalmente acrescenta um viés e aplica uma função de ativação. Redes organizam essas unidades em camadas; durante o treinamento, os parâmetros são ajustados para melhorar o desempenho na tarefa.

A inspiração no cérebro é uma analogia. Neurônios artificiais não reproduzem toda a complexidade dos neurônios biológicos.

## Multimodalidade

A aula apresenta a evolução dos sistemas de conversa, como ELIZA, até sistemas capazes de trabalhar com diferentes modalidades.

**IA multimodal** pode processar ou combinar mais de um tipo de informação, como **texto, imagens, áudio e vídeo**. As modalidades aceitas e produzidas dependem do sistema; nem todo modelo oferece todas elas.

Deep Learning ajuda a viabilizar muitas dessas aplicações. **Multimodalidade** descreve os tipos de informação utilizados, enquanto **Deep Learning** descreve uma abordagem de aprendizado. Os conceitos estão relacionados, mas têm significados diferentes.

## Pontos para revisão

- IA abrange mais tarefas do que conversar em linguagem natural.
- Machine Learning aprende padrões a partir de dados.
- Deep Learning utiliza redes neurais com múltiplas camadas.
- Treinamento ajusta o modelo; inferência utiliza o modelo treinado.
- Contexto e padrões aprendidos podem contribuir para respostas relevantes, sem garantir sua correção.
- A revista de Pokémon foi usada para ilustrar associações e diferentes interpretações humanas.
- Multimodalidade envolve diferentes tipos de informação, como texto, imagem, áudio e vídeo.
